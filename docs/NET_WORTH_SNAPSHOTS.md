# Net Worth Snapshots

Snapshots remain immutable records of the values known when recorded. The dashboard's **Record snapshot** action captures the selected-currency asset total, liability total, portfolio value, and asset/liability category breakdowns. It allows one automatic snapshot per calendar date; an existing snapshot can be edited from the Snapshots tab for a documented correction.

Historical charts use stored snapshot totals only. Today's live values may be appended as a current point, but they are never copied into missing prior months. Portfolio value history is available only for snapshots that include an investment value. The existing manual snapshot form supports entering historical totals and portfolio value.

Scheduled snapshots are not configured. Snapshot creation is manual and uses the existing offline-first record store and sync queue.
