# Debt payments and Paycheck Planner

A debt payment can be assigned to an existing paycheck by storing that paycheck's ID on the debt payment record. The Paycheck Planner includes linked debt records in its reserved debt allocation total. A planned record remains a funding plan and is not marked paid or copied into expenses. Recording an actual payment updates the matching planned occurrence when possible, so that assignment is not counted twice.

Only existing paycheck records are selectable. The Debt Tracker remains usable without a paycheck. Assignments are not a bank transfer, a bill payment, or a new ledger transaction. The same debt payment should not also be represented as a separate paycheck expense allocation unless the user intends both amounts to reserve funds.
