# Savings dashboard enhancements

The Savings Goals tool now shows a six-card KPI strip, goal progress list, selected-goal hero donut, savings trend, movement comparison, goal comparison, emergency coverage gauge, required-vs-actual chart, activity timeline, and selected-goal details. Existing Goals and Contributions ledger tabs remain the editing and export surface.

## Data and allocation conventions

Goal balances are calculated as opening balance plus recorded contributions minus recorded withdrawals, clamped at zero for display. These are goal allocations; the app does not automatically import bank savings account balances. Treat each goal as a distinct allocation. The existing data model has no shared-account allocation identifier, so the dashboard cannot detect two goals that represent the same dollars.

A GoalMovement may link a budget transaction, but savings reporting uses the goal movement once and does not add the account transaction again. No transaction or transfer is generated by a planned contribution.

New optional goal fields are stored on existing local-first JSON records: plan start date, planned monthly contribution, contribution frequency, coverage target, and optional annual interest assumption. There is no database migration; older goals remain valid.

## Interactions

- Selecting a goal updates the hero donut, selected-goal KPI requirement, and goal detail panel.
- Trend filters support one goal or all eligible goals and 3, 6, 12, or all months.
- Contribution and withdrawal bars open the underlying records for the selected month.
- Emergency coverage presets are saved on the emergency goal.
- Quick actions navigate to the existing goal or movement ledger forms.
- The Savings Balance Trend can be pinned using the existing dashboard widget system.

The emergency expense baseline is entered on the emergency goal. Annual Budget or Paycheck Planner values are not silently imported because there is no user-confirmed shared baseline service for essential expenses.
