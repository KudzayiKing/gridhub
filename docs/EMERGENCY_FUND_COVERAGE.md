# Emergency fund coverage

Coverage is shown only for a goal marked Emergency with a positive, user-entered monthly essential-expense baseline:

`months covered = current emergency goal balance / monthly essential expenses`

The 3, 6, or 12 month gauge target is a user-selected planning choice saved on the emergency goal, not a recommendation for every user. Without a denominator, the dashboard asks the user to set monthly essential expenses and does not estimate one.

The baseline is manually entered and should be reviewed by the user. The app currently does not derive essential expenses from Annual Budget or Paycheck Planner categories, because there is no shared, confirmed classification service. This prevents assumptions that all expense categories are essential.
