# Free Tools conversion and privacy

Each calculator CTA points at its corresponding existing application route and communicates whether access is free or plan-dependent. Unauthenticated visitors pass through `/login?next=<internal app path>`; the existing auth callback preserves that local return route.

When clicked, the browser writes a versioned, same-tab sessionStorage draft with a 30-minute expiry. Draft data is not placed in a URL or sent to the server. After sign-in the destination shows a draft notice. The user can open a review dialog and explicitly confirm import. Debt entries, monthly budget allocations, savings goals, property name/purchase price, and draft invoice lines map to their matching app records. Planned income remains an estimate; no income or expense transactions are created. Rental assumptions beyond property name and purchase price remain estimates. Profit-margin analysis has no matching record type and is not imported. Invoice records stay draft and are never marked sent or paid. Returning to the calculator restores the values.

Conversion events are first-party and sent only after an explicit opt-in on the calculator page. Payloads contain only a calculator ID, funnel stage, and random session ID; they never include input values, balances, prices, income, invoice content, names, or account IDs. The Marketing admin report aggregates the last 90 days. Apply `supabase/migrations/0003_marketing_events.sql` to enable storage and reporting.
