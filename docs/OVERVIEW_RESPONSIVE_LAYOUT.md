# Overview responsive layout

Desktop places the attention panel beside a compact, two-column KPI group. The first pinned chart can use the full content width; remaining charts use the saved half/full preference. The tool launcher follows the dashboard insights and collapses to four tools until expanded.

At desktop widths, customization uses a sticky right panel while the dashboard remains visible. Below the wide-screen breakpoint, customization uses the shared Radix dialog behavior as a slide-up sheet, including Escape handling, focus management, backdrop, and the device safe-area inset. Mobile quick actions remain available below the primary charts.
