# Free Tools SEO

Each public page has a stable canonical URL at `https://gridhub.online/free-tools/{id}`, an individual title, description, Open Graph and Twitter metadata. `app/sitemap.ts` includes the directory and each catalog route. `app/robots.ts` allows public pages while disallowing private app, login, admin, onboarding, and API paths.

The public marketing shell supplies the existing navigation and footer. Calculator methodology, limitations, FAQ content, and internal related-calculator links render with each page. Do not add review/rating schema. If adding structured data later, include only factual data whose visible page content satisfies that schema.

The Free Tools sitemap URLs use the production origin `https://gridhub.online` directly so preview or local environment settings cannot leak into canonical discovery URLs.
