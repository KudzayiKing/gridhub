# Gridhub AI — Privacy

The claim on the settings page is specific and testable: commands, audio and records stay on the
device. This file is the detail behind it.

---

## What leaves the device

| Data | Leaves? | Where it goes |
| --- | --- | --- |
| Typed command text | No | Stays in memory; optionally written to local history |
| Recorded audio | **No** | Held as a Blob in memory, discarded after transcription |
| Transcript | No | Same as typed text |
| Your records (transactions, invoices…) | No | Read locally by app services; never included in a prompt |
| Model file | Download only | Fetched **from** R2 once; nothing is sent to it |
| Runtime assets | Download only | Fetched from our own origin |
| Entitlement | Yes | `GET /api/entitlements` — the normal session request, unchanged |
| Saved records | Yes, when online | The existing sync engine → Supabase, as with manual entry |

No API key exists in the client, and no request is ever made to a model provider.

## What the model sees

`context-builder.ts` builds the prompt from:

- The user's command text.
- The list of actions the account may use (id, one-line description, one example).
- **Up to 24 record names per relevant collection** — category names, account names, debt names —
  so "the Visa" can be resolved to a real record.

It does **not** include balances, totals, amounts, dates, ids, or the database. Every number the user
sees is computed by `lib/calc/*`, not generated by the model. The model's job is to pick an action
and fill in parameters; it is never asked "what is my balance".

## Audio handling

- The microphone opens only on an explicit tap, and only when a speech model is installed.
- No wake word, no continuous listening, no background capture.
- `MediaRecorder` runs for the duration of the recording only; `releaseStream()` stops every track.
- The Blob is decoded to 16 kHz mono, transcribed locally, and dropped. Nothing is written to disk
  or to a cache.
- There is a 60-second cap so a forgotten recording cannot run away.

## Local history

`ai-privacy.ts` keeps a small, human-readable list of commands in `localStorage` under
`gridhub.ai.history` — separate from IndexedDB so "Clear history" can never touch business data.

- Capped at 40 entries.
- Retention: until the tab closes, 7 days, 30 days, or off.
- `off` deletes the list immediately.
- "Clear history" removes it on demand.

## What is stored, and where

| Key / cache | Contents | Cleared by |
| --- | --- | --- |
| `gridhub-ai-models-v1` (Cache API) | Language model, 1.87 GB | "Remove from this device" |
| `transformers-cache` (Cache API) | Speech model files | "Remove voice" |
| `gridhub-v1-ai-runtime-v1` (Cache API) | WASM runtimes | Runtime version bump |
| `gridhub.ai.model.meta` | Model id, size, hash, install date | Remove |
| `gridhub.ai.stt.meta` | Speech model id, file count, install date | Remove |
| `gridhub.ai.history` | Recent commands | Clear history / retention |
| `gridhub.ai.mutations` | Idempotency ledger, 24 h TTL | Automatic expiry |
| `gridhub.ai.settings` | Enabled, voice, retention, locale | — |

None of these are synced. They are device-scoped, which is also why the settings page says so.

## Prompt injection

Content that tries to talk the model into a different action is contained structurally, not by
instruction:

- The model cannot name an action that is not in the allowlist.
- It cannot produce a valid action without passing that action's Zod schema.
- It cannot widen its own entitlements — `canUseTool` is re-checked at execution.
- It cannot navigate outside `/app`.
- Even a perfectly formed malicious proposal still requires the user to press Confirm.

The prompt tells the model to ignore instructions inside data, but that line is defence in depth, not
the defence. `tests/ai-safety.test.ts` asserts the structural gates.

## Honest limits

- The model runs in the same browser as the app; a compromised browser extension can read what a
  compromised browser extension can always read.
- Local history is not encrypted. It is small and local, not a secret store.
- A user who exports their data exports their records, not the AI's history.
